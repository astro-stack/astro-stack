## Featured projects

### [Django Orbit](https://github.com/astro-stack/django-orbit)

**AI agent-native observability and debugging for Django.**

Django Orbit records requests, SQL queries, logs, exceptions, cache operations, jobs, permissions, storage, and AI/LLM metadata in one coherent timeline. It provides a separate dashboard and read-only MCP tools so developers and coding agents can investigate runtime behavior without modifying the host application.

**Why it matters:** debugging is faster when the evidence is connected. Orbit groups related events, bounds agent-facing output, masks sensitive fields, and turns an incident into a structured handoff for the next engineering step.
